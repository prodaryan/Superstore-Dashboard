# 📊 Superstore Sales Analytics Dashboard

An interactive business intelligence and sales analytics dashboard built using **Python**, **Pandas**, and **Plotly** in **Google Colab**.

This project analyzes sales performance, profitability, customer segments, product trends, and regional insights using the popular Superstore dataset.

---

# 🚀 Project Overview

The goal of this project was to perform end-to-end exploratory data analysis and build a professional dashboard that provides actionable business insights through interactive visualizations.

The dashboard focuses on:

- Sales Performance Analysis
- Profitability Insights
- Regional Trends
- Customer Segment Analysis
- Product Performance
- Business Recommendations

---

- Python

- Jupyter Notebook

# 📈 Dashboard Features

✅ KPI Metrics  
- Total Sales  
- Total Profit  
- Total Orders  
- Total Customers  

✅ Interactive Visualizations  
- Monthly Sales Trend  
- Profit by Category  
- Sales by Region  
- Top 10 Products Analysis  
- Customer Segment Analysis  
- State-wise Sales Distribution  
- Sales vs Profit Analysis  

✅ Business Insights  
- Top-performing categories  
- Most profitable regions  
- Discount impact analysis  
- Revenue trends and opportunities  

---

# 📊 Key Business Insights

- Technology category generated the highest overall profit.
- Certain high-discount products negatively impacted profitability.
- The West region showed strong sales performance compared to other regions.
- Customer segment analysis revealed differences in purchasing behavior and revenue contribution.
- Some products generated high sales but low profit margins.

---

# 🧹 Data Cleaning & Preparation

The dataset was cleaned and processed before visualization by:

- Removing duplicate records
- Handling missing values
- Converting date columns
- Creating time-based features for trend analysis
